# STUDY — Assignment Manager

A free, dark forest-green assignment tracker designed for iPhone Home Screen use.

## Features
- Today's assignments, upcoming assignments, and overdue assignments
- Add, edit, delete, and mark assignments complete
- Monthly calendar with due-date indicators
- Saves assignments in this browser on this device
- Installable as a Home Screen web app
- Basic offline app-shell caching after the first visit

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com.
2. Create a new **public** repository named `study-assignment-app`.
3. Upload all files from this folder to the repository's top level (not the ZIP file).
4. Open the repository's **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then Save.
7. Wait for GitHub Pages to publish. Your site address will look like:
   `https://YOUR-USERNAME.github.io/study-assignment-app/`

## Add to iPhone
1. Open the published address in **Safari** (not an in-app browser).
2. Tap the Share button (square with an upward arrow).
3. Scroll and tap **Add to Home Screen**.
4. Keep the name `STUDY`, then tap **Add**.

## Important storage note
Assignments are stored in the browser's local storage on the device. They do not automatically sync between devices, and clearing Safari website data can erase them. Keep a backup of important deadlines elsewhere.
